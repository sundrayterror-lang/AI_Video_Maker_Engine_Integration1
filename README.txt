AI VIDEO MAKER — ENGINE INTEGRATION UPDATE

This ZIP contains:
- android/: Android Studio project with black/purple UI and image-to-video upload flow.
- backend/: secure Node.js API that calls the fal.ai Ovi image-to-video model.

This is NOT a deployed service and is not yet a ready-to-install APK. Real generation requires a server deployment and an account owner to configure a provider secret in the server environment. The app intentionally contains no API key.

Start with backend/SETUP.txt.
